# Quantum Meteo — parameter-driven atmosphere prototype

## Запуск
Загрузить **все файлы папки `storm-sim/`** в одноимённую папку GitHub Pages. Открыть `.../storm-sim/`. Нужен интернет для Three.js, Leaflet и тайлов OpenStreetMap; WebGL должен быть доступен.

## Новая архитектура интерфейса
- `index.html` — сначала выбираются параметры термодинамики/ветра и точка на карте; симуляция не стартует автоматически.
- `ground.html` — основная свободная 3D-сцена с орбитальным обзором; вид с земли включается отдельной кнопкой.
- Нет выбора готовых сценариев: начальное развитие задаётся CAPE, влажностью, LCL, сдвигом, термическим контрастом и ветром.
- Облака стартуют из нулевого размера и постепенно растут. Визуальная форма наковальни вытягивается вдоль вектора сдвига. Солнце освещает сцену, присутствуют рельеф, лес, дальний горизонт, периферические облака, дождь и молнии.
- Можно изменять CAPE, влажность, сдвиг и ветер во время наблюдения. Есть пауза, сброс, включение молний и синтезированного эмбиента.

## Ограничения
Это локальная интерактивная **приближённая модель**, не NWP/CFD и не реальный прогноз. CAPE и прочие настройки напрямую управляют визуальной моделью роста, а не численно интегрируемой атмосферой. География выбранной точки пока не загружает настоящую высотную модель рельефа; ландшафт процедурный. Громовой эмбиент пока не имеет корректной задержки распространения, поэтому это общий атмосферный звук, а не физическая пространственная акустика.

## Проверки
Синтаксис JS можно проверить Node.js командой `node --check` для каждого `.js`. Визуальный WebGL запуск нужно проверить в браузере после публикации; автоматический браузерный тест в среде сборки не выполнялся. Не считать визуальную проверку пройденной без фактического запуска.
