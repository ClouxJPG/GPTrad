# Quantum Meteo — Atmosphere v3.1

Отдельный проект для GitHub Pages. Корневой `index.html` репозитория менять не требуется: загружайте содержимое папки `storm-sim` в одноимённую подпапку.

## Функции
- Настройка атмосферных начальных условий до запуска.
- Отдельный раздел «Зона моделирования»: размер области 40–160 км и ландшафт — хвойный лес, смешанный лес/поля или открытая равнина.
- Процедурный 3D-рельеф и инстансированная растительность; зона влияет на размер поверхности, плотность растительности и область дождевых частиц.
- Отдельный свободный обзор и переключение на вид с поверхности.
- Осадки отображаются с оценкой интенсивности в мм/ч после контактов дождевых частиц с рельефом.

## Установка на GitHub Pages с iPhone
1. Распакуйте архив в приложении «Файлы».
2. В репозитории создайте `storm-sim`, если её ещё нет.
3. Загрузите в неё все файлы из папки `storm-sim`, сохраняя структуру и имена.
4. Откройте `https://clouxjpg.github.io/Daradar/storm-sim/` после публикации Pages.

## Ограничения модели
Это интерактивная визуальная модель, не численный прогноз. Значение осадков в мм/ч — визуальная оценка, получаемая из числа контактов моделируемых дождевых частиц с поверхностью и параметров конвекции; оно не откалибровано по физической площади осадочного столба и не предназначено для измерений/прогноза. Рельеф процедурный, а не реальная высотная карта выбранных координат. Three.js и Leaflet загружаются с CDN, поэтому для первой загрузки требуется интернет.
