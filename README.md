# Quantum Meteo — Earth & Ground prototype

Это отдельный браузерный прототип с двумя режимами:
- `index.html` — интерактивная карта Земли, выбор координат кликом/маркером и выбор сценария.
- `ground.html` — отдельная 3D-сцена с камеры на высоте 2,4 м: геометрический рельеф, дальние гряды, лесные массивы, плотная многослойная грозовая система, соседние ячейки, дождевые завесы и молнии.

## Размещение на GitHub Pages
1. Создайте папку `storm-sim` в репозитории.
2. Загрузите в неё все файлы архива, сохранив структуру.
3. Откройте `https://<username>.github.io/<repo>/storm-sim/`.
4. Выберите место на карте и нажмите «Открыть вид с Земли».

## Технологии и ограничения
- Three.js загружается с jsDelivr; Leaflet и тайлы карты — с unpkg/OpenStreetMap. Для первого запуска нужен интернет.
- Визуальные облака построены из деформированной 3D-геометрии и обычных материалов Three.js, не из одного full-screen шейдера. Рельеф — сетка высот, лес — instanced geometry.
- Это визуальный прототип, не фотограмметрия и не CFD/NWP-модель. CAPE и высота базы в HUD — демонстрационные сценарные значения. Локализация точки пока меняет координаты наблюдателя в интерфейсе, но не загружает реальную географию выбранного места.
- На устройстве без WebGL страница покажет ошибку вместо пустого экрана.

## Проверки
Перед публикацией выполнена проверка синтаксиса модулей и ссылок на локальные файлы. Визуальная проверка требует запуска в браузере с доступом к CDN и WebGL; не считать её пройденной, если не открыт `ground.html` в браузере.
