# Quantum Meteo — Atmosphere: Landscape Selection

Отдельный проект для GitHub Pages. Корневой `index.html` основного репозитория менять не требуется: загружайте содержимое этой папки в `storm-sim/`.

## Возможности
- Начальные атмосферные параметры задаются до запуска.
- Выбор ландшафта: хвойный лес, смешанный лес и поля, открытая равнина, холмы и горные гряды.
- Выбор места на карте полностью удалён: никаких карт, координат или маркеров.
- Размер 3D-зоны 40–160 км.
- Отдельный свободный обзор и переключение на вид с поверхности.
- Осадки на поверхности отображаются как приблизительная интенсивность в мм/ч.

## Установка через iPhone
1. Распакуйте ZIP в приложении «Файлы».
2. В репозитории создайте папку `storm-sim`, если её ещё нет.
3. Загрузите в неё все файлы из одноимённой папки архива.
4. После публикации GitHub Pages откройте `https://clouxjpg.github.io/Daradar/storm-sim/`.

## Ограничения
Это учебная визуальная модель, не численный прогноз. Осадки в мм/ч оцениваются по моделируемым частицам и не откалиброваны для измерений. Рельеф процедурный, а не реальная высотная карта. Three.js загружается с CDN, поэтому для первой загрузки нужен интернет.
